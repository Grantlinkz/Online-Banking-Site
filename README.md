# Online Banking Site

A Online Banking Website Without Automated FIAT Payment Gateway.

Overview
- A web application simulating online banking features (accounts, transfers, history) without any automated fiat payment gateway.
- Primary languages: JavaScript, CSS, PHP, SCSS, HTML, Hack.

Key Features
- User authentication and account dashboard
- Balance overview and transaction history
- Internal account transfers
- Responsive UI (desktop + mobile)
- Backend logic in PHP / Hack

Tech Stack
- Frontend: HTML, JavaScript, CSS, SCSS
- Backend: PHP, Hack
- Database: MySQL

Getting Started (development)
1. Clone:
   git clone https://github.com/Grantlinkz/Online-Banking-Site.git
2. Configure a local PHP environment (XAMPP / MAMP / LAMP) and point the web root to the project folder.
3. Create a database and import any provided schema/sql files (or run provided setup scripts).
4. Update config files (database credentials, base URL).
5. Start the server and open the app in your browser.

Usage
- Register or use demo credentials (if provided).
- Create/view accounts, make internal transfers, and review transaction history.
